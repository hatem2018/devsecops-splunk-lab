# 🤝 Contributing Guidelines

Thank you for your interest in contributing to **DevSecOps Splunk Lab**!
This project is designed as a reference and educational environment for end-to-end Splunk automation on Kubernetes (K3s).

---

## 🧠 Before You Start

1. **Read the README.md**
   Make sure you understand the architecture, tooling, and deployment flow.

2. **Fork the Repository**
   Create your own copy of the repo to work on your feature or improvement.

3. **Clone your Fork**
   ```bash
   git clone https://github.com/<yourusername>/devsecops-splunk-lab.git
   cd devsecops-splunk-lab
